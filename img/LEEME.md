# Capturas de pantalla

Los 37 archivos de esta carpeta son marcadores de posición generados para el curso. Cada uno
muestra una ventana simulada con el número de captura y la descripción de lo que debe verse.

Para poner las capturas reales, sustituye cada archivo por tu imagen conservando exactamente el
mismo nombre. No hace falta tocar las lecciones, porque ya apuntan a estas rutas.

El esquema de nombres es `captura-LL-NN.png`, donde `LL` es el número de lección y `NN` el
número de captura dentro de esa lección, ambos con dos dígitos. Si añades una captura nueva,
sigue el mismo esquema y enlázala desde la lección con

```
::: captura img/captura-09-04.png
Captura 9.4. Descripción de lo que se ve.
:::
```

Conviene que todas tengan una proporción parecida, alrededor de 1280 por 800, y que estén en
PNG. Recorta la ventana del programa sin el escritorio alrededor, y si señalas un elemento
concreto, hazlo con un recuadro de color en lugar de una flecha, que se lee mejor en pantallas
pequeñas.
