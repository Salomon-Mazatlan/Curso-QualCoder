# Archivos de práctica

Aquí van los materiales descargables de las lecciones. El esquema de nombres es

```
NN-tema-descripcion.ext
```

donde `NN` es el número de lección con dos dígitos, en minúsculas, sin acentos ni espacios y
con guiones medios como separador.

| Archivo | Lección | Para qué se usa |
|---|---|---|
| `05-entrevista-ejemplo.txt` | 5 | Importar un texto plano |
| `05-nota-de-campo.docx` | 5 | Importar un documento con formato |
| `06-encuesta-ejemplo.csv` | 6 | Importar un cuestionario con preguntas abiertas |
| `07-referencias-ejemplo.ris` | 7 | Importar referencias bibliográficas |
| `09-entrevista-cuidado.txt` | 9 | Codificar texto |
| `10-articulo-dos-columnas.pdf` | 10 | Codificar sobre la maqueta de un PDF |
| `10-articulo-resaltado.pdf` | 10 | Importar un PDF con resaltados previos |
| `11-fotografia-campo.jpg` | 11 | Codificar regiones de imagen |
| `12-fragmento-audio.mp3` | 12 | Codificar desde la onda de sonido |
| `12-transcripcion-grupo-focal.txt` | 12 | Marcar hablantes |
| `14-atributos-casos.csv` | 14 | Cargar atributos de los casos |

Sube los archivos a esta carpeta con esos nombres y los enlaces de las lecciones funcionarán
sin tocar nada más. Para agregar otros, revisa el apartado de archivos de práctica de
`GUIA-DE-EDICION.md`.

Antes de subir cualquier material con datos de personas, comprueba que esté anonimizado y que
tengas la autorización para difundirlo. GitHub sirve archivos de hasta 100 MB por archivo, así
que para audio y video conviene recortar o comprimir.
